NORDR Performance Privacy Notice

This preliminary notice describes how information is handled on the current static NORDR Performance website.

Last updated: September 2026

Scope

This notice applies to nordrperformance.com and the NORDR Human Performance System Check as currently published.

System Check

The current System Check operates locally in the user’s browser unless or until server-side submission is implemented.

  • Responses are processed in the browser to generate the System Snapshot.
  • localStorage may be used to preserve assessment progress across page refreshes.
  • Assessment data is not transmitted to NORDR servers in this version of the site.
  • Users can clear stored progress using Start Again.

Please do not enter personal medical information or identifying employee information into the System Check.

Email contact

If you contact NORDR by email at contact@nordrperformance.com, the information you provide will be processed for the purpose of responding to your enquiry and related follow-up.

Analytics

The site may later use privacy-conscious analytics. If analytics are introduced, this notice will be updated to describe what is collected and why.

Cookies and local storage

Aside from browser localStorage used for System Check progress, the current static site does not rely on advertising cookies.

Changes

This notice may be updated as the website develops. Material changes will be reflected on this page.

Contact

Questions about this notice can be sent to contact@nordrperformance.com.

This page is a preliminary privacy notice for the current static website. It is not a claim of full regulatory certification.
